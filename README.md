# VanhCodes — Vanh Love IT

A compact one-page profile for Trần Việt Anh, featuring website design, technology products, direct contact, and the existing source code and social links.

## Project structure

```text
index.html
style.css
script.js
assets/    supplied avatar, frame, verification badge, and music
backups/   original source snapshots
```

Open `index.html` in a browser to view the site. There is no build step, framework, or package dependency. Roboto is loaded from Google Fonts; the page uses a system sans-serif fallback if the font cannot load.

The site honors reduced-motion preferences and does not autoplay audio. The music control reflects actual playback state. Phone copy uses the Clipboard API when available and falls back to the browser copy command.
